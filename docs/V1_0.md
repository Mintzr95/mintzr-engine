# MJU Engine 1.0

MJU 1.0 is the first stable architecture milestone for a mobile-first 2D engine.

## Included
- C++20 runtime and scene/entity model
- Android OpenGL ES 2 renderer and touch bridge
- Camera, input, animation, physics, particles
- UI runtime and editor foundation
- Asset/resource catalog and tilemap data model
- Undo/redo, scene serialization, project settings
- Lightweight command scripting VM for simple gameplay logic
- Debug console and frame counter
- Android editor activity with Arabic-friendly controls
- GitHub Actions configuration for Android CI

## Deliberate scope
The first 1.0 renderer is intentionally dependency-light and uses colored quads. PNG/JPEG decoding, advanced sprite atlas editing, 2D lighting, multiplayer, 3D and a full visual scripting graph are post-1.0 features.
