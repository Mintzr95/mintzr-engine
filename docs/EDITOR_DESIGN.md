# MJU Mobile Editor

The editor is designed around three fixed mobile regions: Hierarchy (left), Canvas (center) and Inspector (right). The canvas is touch-first and keeps controls large enough for phones.

## Implemented in v0.7
- select and drag entities
- create / duplicate / delete
- hierarchy selection
- editable name and position
- visibility and lock flags
- zoom slider
- undo / redo snapshots
- scene save format v2
