# MJU Engine v0.9

Production/editor integration milestone.

## Added
- Runtime UI canvas with anchors, layout and touch hit-testing.
- Input press events separated from held state.
- ResourceCatalog directory import and extension classification.
- TileMap visible-cell query for renderer/editor integration.
- Sprite material/draw-command data types.
- Android app version 0.9.0.

## Design rule
MJU stays mobile-first: systems expose small C++ APIs and the Android editor can consume them without requiring desktop-only tooling.

## Remaining for 1.0
1. Visual texture decoding and sprite atlas rendering.
2. Tilemap renderer and editor painting tools.
3. Real Android audio backend.
4. Script runtime and project packaging.
5. Complete APK/AAB release pipeline and device smoke test.
